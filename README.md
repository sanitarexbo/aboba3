# Finesse CRM 4.0

Полноценный проект с интерфейсом **React + TypeScript**, API на **Node.js + TypeScript** и общей базой **SQLite**.

**Инструкция на русском:** [README_INSTALL_RU.md](README_INSTALL_RU.md)

## Быстрая разработка

Требуется Node.js 22.16+ (предпочтительно Node.js 24 LTS) и npm.

```bash
npm install
npm run build
npm run start
```

Проверка API: `npm run test:api`.

Первого владельца нужно создать отдельно, см. инструкцию по установке.

## Содержимое

В проекте отсутствуют аудио/видеозвонки и записи. Проценты начислений хранятся исключительно на сервере. Денежные переводы осуществляются вручную.
